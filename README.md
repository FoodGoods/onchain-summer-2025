## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/FoodGoods/onchain-summer-2025.git
cd onchain-summer-2025

# Install Foundry
curl -L https://foundry.paradigm.xyz | bash
foundryup

# Deploy contracts
cd advanced-contracts
export PRIVATE_KEY=your_private_key
export BASE_SEPOLIA_RPC_URL=https://sepolia.base.org
./deploy-all.sh
```
